REST API для запуска Lua-скриптов на удалённом сервере и получения агрегированных данных по объектам электроэнергетики. Сервис выступает источником данных для аналитических дашбордов.

## Формат эндпоинтов
``` GET /api/{controller}/scripts/{script_name} ```

| Параметр | Описание |
| --- | --- |
| ```{controller}``` | Имя контроллера, определяющего доменную область (например, Aip или Sapphire) |
| ```{script_name}``` | Имя Lua-скрипта, который будет выполнен на удалённом сервере |

Авторизация производится по данным учетной записи пользователя в Active Directory через Bearer token

**Пример запроса:** ```GET http://{host}/api/Aip/scripts/lines```

## Как это работает
1. Клиент отправляет запрос на эндпоинт вида /api/{controller}/scripts/{script_name}.
2. API валидирует запрос и определяет соответствующий Lua-скрипт.
3. Скрипт передаётся на удалённый сервер исполнения.
4. Lua-скрипт выполняет агрегацию данных по объектам электроэнергетики.
5. Результат возвращается клиенту в виде JSON, который может использоваться как источник данных для аналитических панелей.
